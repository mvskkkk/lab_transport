The project was developed exclusively for educational purposes.
Date of completion: winter 2025
Task:
Определить иерархию подвижного состава железнодорожного транспорта. Создать пассажирский поезд. Реализовать:

1. Подсчёт общей численности пассажиров и багажа.
2. Сортировку вагонов поезда на основе уровня комфортности.
3. Поиск вагонов, соответствующих заданному диапазону числа пассажиров.

Технология: 
- Java 17
- Maven
- Log4j 2
- TestNG
